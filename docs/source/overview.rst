Обзор
=====

Назначение
----------

Проект реализует web-сервис для проверки дипломов. Основной сценарий:

* администратор создает вуз;
* вуз добавляет студентов;
* вуз выпускает дипломы студентам;
* студент видит свои дипломы в личном кабинете;
* любой пользователь может проверить диплом через публичную форму или страницу
  диплома.

Возможности
-----------

* Публичная проверка диплома без авторизации.
* Публичная страница диплома по UUID.
* Личный кабинет с ролями ``admin``, ``university`` и ``student``.
* Управление вузами и пользователями.
* Управление студентами вуза.
* Создание и просмотр дипломов.
* Статусы дипломов: ``valid`` и ``revoked``.
* Журнал проверок дипломов.
* Авторизация через Django sessions.
* Двухфакторная авторизация по email для вузов и студентов.
* Восстановление и смена пароля.
