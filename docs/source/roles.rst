Роли и доступы
==============

admin
-----

Администратор Django или staff-пользователь.

Доступно:

* управление вузами;
* управление пользователями;
* просмотр дипломов;
* просмотр журнала проверок;
* доступ к Django admin.

university
----------

Пользователь вуза.

Доступно:

* управление студентами своего вуза;
* создание дипломов;
* просмотр дипломов своего вуза;
* просмотр журнала проверок своего вуза.

student
-------

Студент.

Доступно:

* просмотр своих дипломов;
* настройки аккаунта.

user
----

Авторизованный пользователь без привязки к вузу или студенту. Такая роль
определяется системой, но основные рабочие разделы рассчитаны на роли
``admin``, ``university`` и ``student``.

Авторизация
-----------

Администратор входит сразу после проверки логина и пароля.

Вуз и студент после проверки пароля получают 6-значный код на email. Код
действует 10 минут. После подтверждения кода создается Django-сессия.
